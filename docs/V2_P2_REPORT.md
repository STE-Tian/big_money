## 本轮做了什么

P2 在 P1 点时刻特征上训练了 Logistic 回归基线（方向概率）和与之配对的 Ridge 回归（预期收益），LightGBM 主模型（预期收益、方向概率、0.1/0.9 分位数半宽作为不确定性），以及对角协方差高斯 HMM。HMM 只输出按训练集发射均值排序后的未标注状态概率，状态个数在每个训练前缀上用 BIC 选择。重叠标签从训练开始就做了 Purging，评估区间之后按配置做了 Embargo。

交易规则预先写在 `configs/v2_p2.yaml`：在 4h 收盘，若 24h 预期简单收益严格大于一轮往返的基准成本 0.0030（单边手续费 0.001，单边滑点 0.0005，两边相加），目标权重为 1，否则为 0。信号交给 V1 回测引擎，在下一根 4h 开盘成交。初始资金 10000 USDT。压力成本使用 `stress_2`：单边手续费 0.002，单边滑点 0.002。压力测试沿用同一套目标权重，不按压力成本重新开仓。

## 本轮没有做

- P3 mean-variance sizing, volatility targeting, drawdown state machine, CVaR, and circuit breakers
- P4 PBO, DSR, nested walk-forward acceptance gates, and bootstrap
- P5 agent extensions
- P6 paper trading and live trading
- LSTM and Transformer models
- EWMA/GARCH as a volatility model
- shorting, leverage, withdrawals, and perpetual orders

## 方法

标签是收盘到收盘的简单收益。4h、12h、24h 分别是 1、3、6 根 4h bar。若中间缺 bar，标签为空，不把两边的价格接上。特征只用该 bar 收盘时已经存在的 P1 列，再加上 `available_time` 不晚于该 4h 收盘、并且不超过 1 小时的最新 1h 特征。

滚动方案是扩展窗口。第一折的验证段选择 Logistic 的 C、Ridge 的 alpha，以及 LightGBM 的 `num_leaves`、`min_child_samples`、`lambda_l2`。选择指标是验证集 log loss，LightGBM 在 log loss 相同的候选里再看 MAE。选出的参数冻结，后面的折只重拟合，不再调参。每一折的训练行都去掉标签与测试区间重叠的样本，并去掉测试区间之后 `embargo_bars` 根决策。验证段相对拟合段同样处理。HMM 在该折测试开始之前的观测上拟合，测试段只用前向滤波概率，不用平滑概率。

线性基线的不确定性是该折 Ridge 的样本内残差标准差。LightGBM 的不确定性是 0.1 与 0.9 分位数预测差距的一半。方向概率的伯努利方差可以由概率本身算出。这些都不是保形区间。主模型的特征贡献用 LightGBM `pred_contrib`（树 SHAP）。`shap.TreeExplainer` 在一小段样本上做了对照，对照结果不参与选模。

## 局限

- 2025-01-18 至 2026-11-26 不是干净的 V2 测试集。报告里与这段重叠的结果只作披露。
- 第一折验证段选出的超参数被冻结。这避免了用后面的折反复挑选最好看的参数，但也把选择绑在最早的一段验证期上。
- 交易规则用 24h 预测去覆盖一次往返成本，而引擎每个 4h bar 都可以改变仓位。期限并不一致。P3 才要求收益和波动率使用同一期限。
- 状态按训练集发射均值排序，换一折之后同一个序号不一定是同一种市场。报告不把它们叫成牛市或熊市。
- 线性不确定性是样本内残差尺度。LightGBM 分位数宽度没有做校准。
- 没有计算 PBO、DSR、嵌套样本外门槛或 bootstrap。因此即使某条曲线赚钱，也不把多试几次之后的选择偏差算进去。
- V1 的 SMA 和动量窗口是 bar 数。用在 4h 上时，日历长度比日线回测短，这里没有为了更好看而加长。

## 复现

在仓库根目录，Windows PowerShell、CMD 和 Linux 都是同一组 `uv` 命令。

```text
uv sync
uv run python scripts/collect_v2.py --start 2020-01-01T00:00:00Z --end 2026-11-27T00:00:00Z
uv run python scripts/validate_v2.py
uv run python scripts/build_v2_features.py
uv run python scripts/train_v2_p2.py
uv run pytest
```

训练脚本写出本文件、`data/reports/v2/p2_summary.json` 和 git 忽略的 `data/reports/v2/p2_predictions.parquet`。预测表 SHA-256：`9d4055dd4c4f684dd23c238a983436e085770b67115b13c263eac005e2a88e3a`（284832 行）。
